

# Simple Django Blog - Learning Project 🎓  

A basic blog project built with **Django** for **learning and practice purposes**.  
Some parts may be incomplete or experimental.  

## 🛠️ Technologies Used  
- **Backend Framework:** Django (Python)  
- **Database:** SQLite (Django default)  
- **Frontend:** Basic HTML + CSS (no frameworks)  

## 🚀 Setup Instructions  
1. Clone the repository:  
   ```bash
   git clone https://github.com/username/your-repo.git
   ```  
2.  use virtual environment (optional but recommended):  
   ```bash
   source venv/bin/activate  # Linux/Mac
   ```  
3. Apply migrations:  
   ```bash
   python manage.py migrate
   ```  
4. Create a superuser (admin):  
   ```bash
   python manage.py createsuperuser
   ```  
5. Run the development server:  
   ```bash
   python manage.py runserver
   ```  
6. Open your browser at [http://localhost:8000](http://localhost:8000).  

## 📌 Implemented Features  
- ✅ Basic blog post system (`Post` model)  
- ✅ Django admin panel for content management  
- ✅ Homepage with post listings  
- ✅ Individual post detail pages
